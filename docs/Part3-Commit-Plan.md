# Part 3 development commit plan

The assessment requires at least 20 meaningful commits for Part 3. The repository currently contains the earlier Part 2 history. Do not create empty commits or split identical changes merely to inflate the count. As you review, test and refine the Part 3 implementation, make commits that each represent a real, reviewable change. Suggested work units:

1. Add the MVC project to the existing solution.
2. Configure MVC routing, static files and session services.
3. Add the typed API HTTP client and base URL configuration.
4. Implement API session-cookie forwarding.
5. Add registration view model and page.
6. Add login view model and page.
7. Implement login, registration and logout API calls.
8. Add role-aware navigation and protected controller actions.
9. Add public event browsing page.
10. Add event detail and category display.
11. Add Participant event enrolment flow.
12. Add Participant enrolment history and cancellation.
13. Add Participant results history.
14. Add Organiser dashboard with event and enrolment totals.
15. Add Organiser event create, edit and delete flows.
16. Add Organiser category management.
17. Add Organiser enrolment status management.
18. Add Organiser result capture.
19. Add profile edit and image upload UI.
20. Add Azure Blob Storage service and API upload endpoints.
21. Add the additive profile-image database update script.
22. Add Dockerfile and Docker Compose configuration.
23. Add Part 3 GitHub Actions workflow and update .NET SDK version.
24. Add setup, verification and video instructions to README.

Commit only after you have reviewed and tested the corresponding change. The assessor may inspect the actual diff and commit history.
